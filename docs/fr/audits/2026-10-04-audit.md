| 📦 Paquet `cn` | C'est le paquet officiel de shadcn (`shadcn-ui/cn`), pas un paquet inconnu |

## 🛠️ Corrigé dans cet audit

| | Problème | Correction |
|---|---|---|
| 🔒 | Aucun *header* de sécurité | `next.config.ts` : `frame-ancestors 'none'` et `X-Frame-Options` (pas de *clickjacking*), `nosniff`, `Referrer-Policy`, `Permissions-Policy` (caméra et micro pour ce site seulement) |
| 🔒 | Une page d'offre était téléchargée en entier avant de vérifier la limite de 2 Mo | Lecture en *stream*, arrêtée dès 2 Mo (`lib/offers/fetch-page.ts`) |
| 🐛 | Un *feedback* réutilisé pour une réponse identique gardait « Not in your profile » même après avoir validé le fait, ou citait un fait supprimé | Réutilisé seulement si chaque affirmation et chaque phrase s'appuient sur des *facts* encore validés (`isReusableFeedback`) |
| 🐛 | Ce *feedback* pouvait passer d'une offre à une autre (il juge la pertinence pour l'offre) | Réutilisé seulement pour la même offre (`findSavedFeedback`) |
| 🐛 | Après un changement d'intervieweur, « relire » rejouait l'ancienne voix | Cache audio de l'onglet indexé par question **et** texte, vidé au changement d'intervieweur |
| 🐛 | « Write a new CV » depuis un lien qui fixe une version (`?v=2`) gardait l'ancienne version à l'écran | Après l'écriture, la page montre la dernière version |
| 🐛 | Une réponse vide du modèle cassait la relance avec Anthropic (tour assistant vide refusé) et « Test connection » affichait un succès | Relance sans tour vide ; « Test connection » signale une réponse vide |

## ⚠️ Reste ouvert

| Priorité | Point | Pourquoi ce n'est pas corrigé | Piste |
|---|---|---|---|
| 🟠 Moyenne | **DNS rebinding** : entre la vérification de l'adresse et le *fetch*, le DNS est résolu deux fois | Corriger demande un *dispatcher* undici qui fixe l'IP vérifiée | Ajouter `undici` et un `Agent` avec un `lookup` qui valide l'IP |
| 🟠 Moyenne | **Owner reconnu par son *username* GitHub** : si la propriétaire renomme son compte, quelqu'un pourrait prendre l'ancien nom | Demande une nouvelle *env var* | Comparer l'id GitHub (`providerUserId`) avec un `OWNER_GITHUB_ID` |
| 🟡 Basse | **Pas de Content-Security-Policy complète** | Clerk charge des scripts de ses domaines : à tester dans un vrai navigateur | Politique avec *nonces* (guide Next.js `content-security-policy.md`) |
| 🟡 Basse | **`npm audit` : 7 alertes « high »** dans le CLI `shadcn` (glob, `braces`) | Code de *build* seulement, jamais exécuté avec des données d'utilisateur | Passer `shadcn` en `devDependencies` ; surveiller une version corrigée |
| 🟡 Basse | **Compteurs d'usage** : une ligne par minute utilisée, jamais purgée | Volume faible (instance personnelle) | Purger les lignes `*:minute:*` de plus d'un jour |
