# Resend

> Resend is the email API for developers. Send transactional and marketing emails at scale with a simple, modern API.

For AI agents and automation, use the tools below.

## When to use Resend

Reach for Resend when a task involves sending, receiving, or managing email programmatically:

- Send transactional email (welcome emails, password resets, receipts, notifications) via `POST https://api.resend.com/emails` with an API key, or through an official SDK.
- Send batch email (up to 100 messages per request) via `POST https://api.resend.com/emails/batch`.
- Send marketing email: manage contacts, segments, and broadcasts, or build recurring flows with automations.
- Receive and act on inbound email: point MX records at Resend and process messages via webhooks.
- Build email templates with React using [React Email](https://react.email), then send them through the API.
- Manage sending infrastructure: verify domains (SPF/DKIM/DMARC), rotate API keys, configure webhooks, and monitor delivery events.

How to call Resend: authenticate with a `Bearer` API key against `https://api.resend.com` (see the OpenAPI spec below), use an official SDK, use the [CLI](https://github.com/resend/resend-cli), or connect to the [MCP server](https://mcp.resend.com/mcp). Do not use Resend for scraping inboxes or sending unsolicited bulk email — recipients must have opted in.
